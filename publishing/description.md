# All Drop One Key

**RU** · [EN](#english)

Выбрасывает **весь инвентарь одной клавишей**: основной инвентарь, хотбар, броню и предмет во второй руке.

- Клавиша по умолчанию — **U**. Поменять: *Настройки → Управление → Инвентарь → «Выбросить весь инвентарь»*.
- Каждый стак выбрасывается целиком, как при Ctrl+Q.
- Работает в выживании и творческом режиме.
- **Только клиент** — ставить на сервер не нужно, работает на обычных серверах.
- Не срабатывает, пока открыт чат или любое меню.

**Требования:** Minecraft 26.3, Fabric Loader 0.20.1+, [Fabric API](https://modrinth.com/mod/fabric-api).

---

## English

Drops your **entire inventory with one key**: main inventory, hotbar, armor and offhand.

- Default key: **U**. Rebind it in *Options → Controls → Key Binds → Inventory → "Drop Entire Inventory"*.
- Whole stacks are thrown, just like Ctrl+Q.
- Works in Survival and Creative.
- **Client-side only** — no server install needed, works on vanilla servers.
- Does nothing while chat or any screen is open.

**Requirements:** Minecraft 26.3, Fabric Loader 0.20.1+, [Fabric API](https://modrinth.com/mod/fabric-api).
